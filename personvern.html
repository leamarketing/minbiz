Sist oppdatert 19. november 2026. Første versjon.

Hva vi lagrer

  • E-postadressen din, for innlogging med lenke.
  • Det du selv skriver inn: interesser, ambisjoner, timer per uke, ferdigheter, idéen din, planer, steg og merker.
  • Om du har valgt å vise stjernetegn. Fødselsdato hentes bare fra profilen du eventuelt har i Min dag. Skriver du den inn i MinBiz, blir den liggende i nettleseren din og sendes ikke til oss.

Hvor det lagres

  • Databasen ligger hos Supabase i EU (Stockholm).
  • Innloggingslenken sendes med e-posttjenesten Resend.
  • Selve nettsidene leveres av GitHub Pages. GitHub kan registrere IP-adresse for drift og sikkerhet.
  • Programbiblioteket for innlogging lastes fra jsDelivr, som kan se IP-adressen din når filen hentes.
  • Innloggingen er felles med Min dag på me.voteapp.eu. MinBiz leser bare fødselsdatoen derfra, og bare når du slår på stjernetegn.

Hva vi ikke gjør

  • Ingen sporing, ingen analysepiksler og ingen annonseverktøy.
  • Vi selger ikke data og deler dem ikke med andre.
  • Stjernetegn vises som tradisjon og inspirasjon, og brukes aldri som grunnlag for penger, lån eller avtaler.

Dine rettigheter

Under «Mine data» i appen kan du laste ned alt du har lagt inn i MinBiz som en fil, og slette alt med ett trykk. Innloggingskontoen er felles med Min dag og slettes ikke av dette valget.

Behandlingsansvarlig: Lea-Amdal, enkeltpersonforetak, org.nr. 926 929 763, Storslett. Spørsmål om personvern: bizplanpilot@gmail.com.

Råd

MinBiz er et planleggingsverktøy. Det gir ikke investerings-, skatte- eller juridiske råd. Lenker til offentlige kilder er generelle pekere.
